# Security Policy

## Supported version
The current content on the `main` branch is the supported version of this repository.

## Reporting a vulnerability
Please do not publish exploitable vulnerability details in a public issue. Use GitHub's **Report a vulnerability** option under the repository's Security tab if it is available, or contact the repository owner privately through GitHub.

Include a short description, potential impact, and safe reproduction steps if available. Remove passwords, tokens, personal information, and secrets from logs or screenshots.

Please allow maintainers reasonable time to investigate before disclosing details publicly.
